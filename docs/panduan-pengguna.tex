\pagetitle{5 (opsional)}{Masukkan data dan konversi CLI}{Halaman ini untuk jalur PowerShell. Untuk tombol browser, lanjutkan ke halaman \pageref{pg:web-start}. Contoh memakai nama sampel; sesuaikan dengan file Anda.}
\label{pg:convert}
\step{1}{Buat folder data}
Di File Explorer, buka folder proyek. Buat folder baru bernama \code{data}, lalu
salin file GRIB dari pemilik data ke dalamnya. Jika folder sudah ada, gunakan
folder tersebut.
\begin{terminal}
grib-data-processing\
  grib_to_csv.py
  data\
    PM 10 DAN PM 2,5 MENTAH.grib
\end{terminal}
\step{2}{Periksa nama file}
Di PowerShell pada folder proyek, jalankan:
\begin{terminal}
dir data\*.grib
\end{terminal}
Pastikan nama tampil sesuai. Aktifkan tampilan \textbf{File name extensions}
di Explorer jika perlu memastikan akhiran file; jangan menambahkan \code{.grib}
dua kali.
\step{3}{Jalankan konversi}
Jalankan dua baris ini secara berurutan. Baris pertama menyimpan path dalam
variabel \code{$inputFile}; tanda kutip melindungi nama yang mengandung spasi.
\begin{terminal}
$inputFile = "data\PM 10 DAN PM 2,5 MENTAH.grib"
.\.venv\Scripts\python.exe grib_to_csv.py $inputFile
\end{terminal}
\step{4}{Tunggu pesan sukses}
CLI sekarang memproses semua kelompok yang ditemukan. Untuk sampel proyek,
cuplikan pesan ringkasnya adalah (identitas disingkat):
\begin{terminal}
EXPORTED group ...: 3168 rows; route=yearly
CSV: ...__dataType-an__numberOfPoints-1639__group-ID.csv
XLSX: ...__dataType-an__numberOfPoints-1639__group-ID.xlsx
\end{terminal}
Setiap kelompok mempunyai hasil sendiri. Cara memeriksa dan memilih kelompok
ada pada halaman \pageref{pg:web-groups}; mode lama tersedia lewat
\code{--legacy-single} jika memang diperlukan.
\begin{panel}{Untuk penggunaan berikutnya}
Buka PowerShell, masuk lagi ke folder proyek (halaman \pageref{pg:powershell}), lalu ulangi langkah
di halaman ini untuk file baru. Environment tidak perlu dibuat ulang jika
masih tersedia. Jumlah baris dan variabel file Anda bisa berbeda.
\end{panel}

\pagetitle{6}{Temukan dan buka hasil}{CSV dan Excel berisi tabel yang sama. Folder hasil default berada di samping file input.}
\label{pg:output}
\step{1}{Buka folder hasil di Explorer}
\begin{terminal}
data\
  PM 10 DAN PM 2,5 MENTAH.grib
  output_PM 10 DAN PM 2,5 MENTAH\

Tanda \code{...} hanya menyingkat nama sumber pada ilustrasi. File sebenarnya

\step{2}{Buka Excel}
Klik dua kali file \code{.xlsx}. Jika Windows meminta aplikasi, pilih Excel
atau aplikasi spreadsheet yang mendukung XLSX. Baris pertama berisi nama kolom;
baris berikutnya berisi data. Jangan mengubah data mentah saat memeriksa hasil.

\begin{center}
\small\setlength{\tabcolsep}{7pt}
\begin{tabular}{rrrrll}
\toprule
\textbf{year}&\textbf{month}&\textbf{day}&\textbf{hour}&\textbf{pm2p5}&\textbf{pm10}\\
\midrule
2024&8&1&0&nilai GRIB&nilai GRIB\\
2024&8&1&3&nilai GRIB&nilai GRIB\\
\bottomrule
\end{tabular}\par
\footnotesize Ilustrasi susunan kolom; bukan angka konsentrasi contoh.

\step{3}{Pilih format yang sesuai}
XLSX paling mudah untuk melihat tabel di Excel. CSV adalah teks dengan pemisah
koma; bisa dibuka di editor teks atau diimpor melalui menu \textbf{Data / From
Text/CSV} pada aplikasi spreadsheet. Jika CSV tampak menjadi satu kolom, pilih
pemisah koma saat mengimpor. Anda juga bisa mengunggah hasil ke AI browser untuk
dibantu membaca tabel (halaman \pageref{pg:ai-browser}).
\par\textbf{Angka sangat kecil tetap dipertahankan.} Misalnya
\code{3.2129265e-08} berarti $3.2129265\times10^{-8}$, bukan error.
Periksa satuan aslinya sebelum menafsirkannya sebagai konsentrasi tertentu.

\begin{panel}{Hasil dengan nama sama akan ditulis ulang}
Salin hasil lama ke folder lain jika ingin menyimpannya sebelum mengulang
konversi. Tutup file XLSX yang sedang dibuka di Excel sebelum menjalankan ulang.
\end{panel}

\end{terminal}
Salin seluruh perintah pada satu baris. Hasilnya disimpan dalam
\code{data\hasil} dengan nama file yang sama seperti contoh.

\pagetitle{7}{Pahami titik dan kolom waktu}{Konversi menjaga cara baca notebook. Memahami maknanya mencegah salah menafsirkan tabel.}
\label{pg:semantics}
\textbf{Titik lokasi: koordinat terakhir pada kedua sumbu}\par
Script mengambil satu titik untuk tiap waktu, yaitu latitude terakhir dan
longitude terakhir. Ini bukan rata-rata seluruh wilayah. Pada sampel, titiknya
adalah latitude \textbf{-7.5}, longitude \textbf{111.0}.
\begin{center}
\par\noindent\begin{tikzpicture}[scale=0.78]
\draw[step=1,blue!35] (0,0) grid (5,3);
\foreach \x in {0,...,5} \foreach \y in {0,...,3} \fill[blue!45] (\x,\y) circle (2pt);
\fill[teal] (5,0) circle (5pt);
\draw[->,teal,thick] (7.8,0.7)--(5.2,0.05);
\node[align=left,anchor=west,font=\small] at (6,1.4) {Titik yang diambil\\latitude terakhir\\longitude terakhir};
\node[below,font=\small] at (5,-0.2) {111.0};
\node[left,font=\small] at (-0.1,0) {-7.5};
\node[above,font=\small] at (2.5,3.1) {Ilustrasi grid; ukuran disederhanakan};
\end{tikzpicture}\par
\end{center}
\begin{panel}{Dua jalur waktu yang didukung}
\textbf{Yearly}: dimensi waktu, latitude, longitude. Kolom tanggal dan
\code{hour} berasal dari timestamp referensi \code{time}.

\textbf{Monthly single}: dimensi waktu, step, latitude, longitude. Tanggal
tetap tanggal referensi; \code{hour} berisi durasi forecast \code{step} dalam
jam bulat. Pecahan jam dipotong mengikuti notebook.
\end{panel}
\begin{center}
\begin{tabular}{@{}lll@{}}
\toprule
\textbf{Contoh monthly}&\textbf{Hasil tabel}&\textbf{Artinya}\\
\midrule
time: 1 Jan 2025&year=2025, month=1, day=1&Tanggal referensi\\
step: 27 jam&hour=27&Durasi, bukan jam harian\\
\bottomrule
\end{tabular}\par
\end{center}
Script tidak mengganti tanggal menjadi tanggal \code{valid_time}. Jangan
menganggap \code{hour=27} sebagai kesalahan atau mengubahnya ke jam 03 sendiri.
Satuan variabel dan zona waktu harus diperiksa dari metadata GRIB atau pemilik
data; jangan menganggap semua data memakai satuan tertentu atau WIB.
Sampel lokal memiliki jalur yearly. Jalur monthly juga diuji melalui GRIB kecil
buatan ecCodes; ini bukan tambahan sampel observasi nyata.

\pagetitle{8}{Mulai Ruang GRIB}{Ruang GRIB adalah antarmuka browser lokal proyek ini. Anda memilih data melalui tombol; tidak perlu mengetik perintah konversi untuk setiap file.}
\label{pg:web-start}
\step{1}{Pastikan installer sudah selesai}
Ikuti halaman \pageref{pg:packages}: klik dua kali \code{install.cmd} dan tunggu
\textbf{Instalasi selesai}. Paket browser dan converter sudah dipasang bersama;
tidak perlu memasang paket lagi sebelum setiap penggunaan.
\step{2}{Jalankan launcher}
Klik dua kali \code{start-web.cmd} di Explorer, atau jalankan dari PowerShell:
\begin{terminal}

\pagetitle{9}{Kenali dan pilih kelompok GRIB}{Satu file dapat memuat beberapa kombinasi filter. Aplikasi menemukan pesan yang benar-benar ada, bukan menebak daftar fc/em/es.}

Pilih sumber seperti pada halaman \pageref{pg:web-input}, lalu klik
\textbf{Periksa kelompok GRIB}. Tabel menampilkan sumber, group ID,
\code{dataType}, \code{numberOfPoints}, parameter, jumlah pesan, dan identitas
\code{filter_by_keys}. \textbf{filterKey} berarti pasangan nama kunci dan nilai;
bukan properti GRIB baru.

\footnotesize Contoh kombinasi yang diverifikasi pada GRIB buatan uji ecCodes.
File Anda dapat memiliki kombinasi lain; tidak dibuat pasangan fiktif.
\end{center}
\step{2}{Biarkan semua atau pilih subset}
Pada \textbf{Kelompok yang dipilih}, \textbf{semua kelompok menjadi pilihan
awal}. Hapus pilihan yang tidak diperlukan jika hanya ingin beberapa filter.
Langsung menekan preview/proses sebelum discovery juga menemukan kelompok lalu
menggunakan semuanya. Jika semua pilihan dihapus, tombol baca/proses dinonaktifkan.
\begin{panel}{Kelompok yang terlihat sama masih bisa berbeda}
Geometri grid, level, jenis step, atau cakupan waktu antarvariabel dapat berbeda
walau jumlah titik sama. Group ID membedakannya. Pesan dipartisi tepat sekali;
kelompok dibaca dari salinan pesan aslinya, tidak dicampur dengan filter luas.
\end{panel}
\step{3}{Pahami jalur waktu dan kegagalan parsial}
Yearly/monthly dipilih otomatis dari dimensi \emph{masing-masing kelompok},
bukan nama file atau dataType. Dimensi yang tidak didukung dilaporkan gagal;
kelompok lain tetap diproses. Discovery input
terpotong ditandai tidak lengkap; pesan duplikat ambigu tidak dipilih diam-diam.
Nama hasil selalu memuat \code{dataType}, \code{numberOfPoints}, dan group ID.

\step{1}{Pilih cara memasukkan data}
\begin{itemize}[itemsep=2pt]
\item \textbf{Unggah berkas}: pilih satu atau beberapa file GRIB.
\item \textbf{Unggah folder}: pilih folder; GRIB di subfolder ikut diunggah.
\item \textbf{Folder lokal}: tempel alamat folder pada komputer aplikasi.

Panel \textbf{Periksa data} menampilkan 20 baris pertama, jumlah baris/variabel/

bukan tabel seluruh grid. Pilihan preview selalu berlabel sumber, group ID,
dataType, dan jumlah titik, sehingga setiap filter dapat diperiksa sendiri.

Klik \textbf{Proses berkas terpilih}. Tiap kelompok mempunyai status sendiri;
jika satu kelompok gagal, kelompok lain tetap diproses. Buka detail masalah bila perlu.
\begin{panel}{Filter hanya bila Anda mengetahui kuncinya}
\textbf{Filter lanjutan (opsional)} memuat \code{dataType} dan
\code{numberOfPoints}. Kosong berarti semua kelompok nyata; isian hanya
mempersempit discovery. Perubahan sumber, pilihan kelompok, atau filter
membatalkan cuplikan/hasil lama.
\end{panel}
